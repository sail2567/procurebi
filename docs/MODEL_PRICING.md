## 1. 先看结论

1. **旗舰模型输入价集中在 $2–10/百万，输出价是输入的 4–5 倍。** Claude Fable 5.1、GPT-6 Astra、Claude Mythos 5 都是 $10/$50；Claude Opus 5.5 是 $4/$20。
2. **中端模型是采购主力。** GPT-6.1 Sol、Claude Sonnet 5.5、Gemini 4 Argon（促销）都在 $2/$10 附近，综合成本约为旗舰的 1/5。
3. **国产模型价格低一个数量级。** DeepSeek Flash 错峰 ¥1/¥4、GLM-5.3-Flash ¥0.8/¥2.8、MiniMax M3.1-Flash ¥1/¥4，折算后约为海外旗舰的 1/20–1/50。
4. **缓存是最大的成本杠杆。** 缓存命中价通常是输入价的 5%–20%；Kimi K3 缓存命中 ¥2 vs 未命中 ¥20，差 10 倍。
5. **批量调用普遍 5 折。** Anthropic、OpenAI、Google、DeepSeek（错峰）、豆包都有批量或错峰折扣；xAI 部分模型批量 8 折。
6. **长上下文会触发阶梯加价。** Gemini 3.1 Pro 超过 200K 后输入翻倍；GPT-6 Astra 超过 272K 后 $20/$75；MiniMax M3 超过 512K 后价格翻倍。
7. **订阅套餐和 API 是两套账。** Claude Pro/Max、ChatGPT Plus/Pro、Kimi 会员、GLM Coding Plan 卖的是产品额度，不等于 API token 单价；做采购比价时必须分开建模。

## 5. Token 计费规则

### 5.1 基本公式

```text
单次成本 =
    输入 tokens   × 输入单价
  + 输出 tokens   × 输出单价
  + 缓存写入 tokens × 缓存写入单价
  + 缓存命中 tokens × 缓存命中单价
  + 工具/检索/存储等附加费
```

多数厂商按 **输入、输出分别计价**；输出价通常是输入价的 4–5 倍，因此控制输出长度比压缩输入更有效。

### 5.2 缓存

- **缓存写入**：首次把前缀写入缓存时收费，通常高于普通输入价。
- **缓存命中**：命中后按折扣价计费，常见为输入价的 5%–20%。
- **TTL**：Anthropic 默认 5 分钟，1 小时约 2 倍；Kimi K3 5 分钟 ¥20、1 小时 ¥40。
- 适合缓存：系统提示词、工具定义、长合同、固定知识库前缀。

### 5.3 批量与错峰

- Anthropic / OpenAI / Google：Batch 约 5 折。
- DeepSeek：错峰时段 5 折（非高峰）。
- 豆包：批量约 5 折。
- xAI：Grok 4.3 / 4.20 批量 8 折。
- 适合批处理：日志分析、批量标注、离线报表、历史账单核对。

### 5.4 长上下文阶梯

- Gemini 3.1 Pro：≤200K $2/$12，>200K $4/$18。
- GPT-6 Astra：≤272K $10/$50，>272K $20/$75。
- MiniMax M3：≤512K ¥2.1/¥8.4，>512K ¥4.2/¥16.8。
- 智谱 GLM-5 系列：≤32K 与 >32K 两档。

### 5.5 推理与思考 token

## 7. 采购比价方法

### 7.1 统一口径

1. **统一单位**：全部折算为每百万 token；人民币按 7.2 折算美元。
2. **区分场景**：对话、代码、长文档、批处理分别建价格模型。
3. **区分价格类型**：目录价、促销价、合同折扣、批量价、错峰价。
4. **计入缓存**：按预计缓存命中率计算加权输入价。
5. **计入输出比例**：输出价通常是输入价的 4–5 倍，输出占比决定总成本。

### 7.2 加权成本公式

```text
加权输入价 = 缓存命中率 × 缓存价 + (1 - 缓存命中率) × 输入价
单次成本   = 输入 tokens × 加权输入价 + 输出 tokens × 输出价 + 附加费
```

示例：某业务每月 1 亿输入、2,000 万输出，缓存命中率 60%。

- Claude Opus 5.5：`1亿 × (0.6×0.20 + 0.4×4) / 1e6 + 2000万 × 20 / 1e6 = 184 + 400 = $584/月`
- Claude Sonnet 5.5：`1亿 × (0.6×0.10 + 0.4×2) / 1e6 + 2000万 × 10 / 1e6 = 86 + 200 = $286/月`
- DeepSeek Flash（错峰）：`1亿 × (0.6×0.02 + 0.4×1) / 1e6 + 2000万 × 4 / 1e6 = ¥81.2/月`（约 $11.3）

### 7.3 谈判要点

- **阶梯折扣**：承诺月用量换单价，通常比公开价低 10%–30%。
- **缓存承诺**：固定系统提示词和知识前缀，直接降低输入成本。
- **批量窗口**：非实时任务走 Batch，普遍 5 折。
- **错峰调度**：DeepSeek 错峰 5 折，适合离线任务。
- **混合路由**：简单任务走小模型，复杂任务升级旗舰；按流量比例加权。
- **合同条款**：价格有效期、涨价提前通知、配额预警、超量单价、SLA 赔付。
